# Reference Snapshot — 2026-09-18

YASC uses dated reference snapshots because external standards and protocols evolve independently of YASC releases.

## OWASP

- **OWASP Top 10 for Agentic Applications 2026** — published 2025-12-09.  
  https://genai.owasp.org/resource/owasp-top-10-for-agentic-applications-for-2026/
- **OWASP Agent Control Standard (ACS)** — published 2026-09-01; emphasizes inspectability, traceability, instrumentation, and runtime policy hooks.  
  https://genai.owasp.org/resource/agent-control-standard-acs/

- **OWASP Vendor Evaluation Criteria for AI Red Teaming Providers & Tooling v1.0** — published 2026-02-04; distinguishes meaningful testing of advanced systems from jailbreak-only testing.  
  https://genai.owasp.org/resource/owasp-vendor-evaluation-criteria-for-ai-red-teaming-providers-tooling-v1-0/
- **OWASP Practical Guide for Secure MCP Server Development** — published 2026-02-16.  
  https://genai.owasp.org/resource/a-practical-guide-for-secure-mcp-server-development/

## Model Context Protocol

- **MCP Specification 2026-07-28** — stateless core and authorization hardening, including RFC 9207 issuer validation and movement toward client metadata documents.  
  https://blog.modelcontextprotocol.io/posts/2026-07-28/
- **MCP roadmap, 2026-08-22** — agent identity and enterprise-ready security are explicit priority areas.  
  https://blog.modelcontextprotocol.io/posts/mcp-roadmap/
- **MCP Apps authorization** — documents per-server and per-tool authorization patterns.  
  https://apps.extensions.modelcontextprotocol.io/api/documents/authorization.html

The MCP Profile targets `2026-07-28`. Implementations on older or newer revisions must record the negotiated/targeted protocol and adjust tests accordingly.

  https://airc.nist.gov/

## Mapping policy

External identifiers are references, not copied control text. Mappings should be corrected when authoritative upstream material changes. A mapping does not imply endorsement, certification, or full coverage of the external framework.
