# Security Policy

YASC contains defensive security guidance and test definitions. If you find a vulnerability in repository automation or a security issue whose public disclosure could create immediate harm, please avoid posting sensitive exploit details in a public issue.

Use your organization's private reporting channel to contact Yofune Security Research. Before the public repository has an official security contact, open a minimal issue titled `Security contact request` without exploit details.

## Scope

This policy covers repository code, schemas, build automation, and the static site. It does not authorize testing third-party systems referenced by the checklist.
