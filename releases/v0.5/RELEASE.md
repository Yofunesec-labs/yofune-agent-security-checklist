## Scope

This release advances YASC from a control/test baseline into a more complete verification and assurance specification. It retains 52 stable core controls and expands the verification catalog to 58 tests.

## Highlights

- Branded English/Chinese technical whitepapers.
- Verification Plan, Verification Run, Evidence Manifest, Assurance Case, and Conformance Claim artifact chain.
- Security-oracle and side-effect verification guidance.
- Temporal/TOCTOU, queued-action, revocation-propagation, parser-differential, and state-compaction tests.
- Framework-neutral harness for plan/run/evidence workflows.
- Multidimensional coverage model instead of a composite security score.

## Claim discipline

This remains a **Public Draft**, not a certification program. YAL and conformance statements are bounded to the recorded scope, system state, evidence, and revalidation triggers.
